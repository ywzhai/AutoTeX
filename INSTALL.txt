Math Autocomplete for Overleaf

1. Extract this ZIP into a permanent folder.
2. Open chrome://extensions and enable Developer mode.
3. Click Load unpacked and select this extracted folder (contains manifest.json).
4. Reload Overleaf and use the Code Editor.

Type within LaTeX math: repeat the first three characters of an existing formula,
or start a sequence such as x_1,x_2. Grey text previews the suggested continuation.
Tab accepts. Esc dismisses. Undo removes acceptance.

The extension popup controls features and the default final index.
Suggestions use only the open source file and run locally. No API key needed.
Unofficial extension; not affiliated with Overleaf.
